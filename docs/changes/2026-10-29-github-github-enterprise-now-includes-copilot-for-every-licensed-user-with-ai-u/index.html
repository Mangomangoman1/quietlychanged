GitHub Enterprise now includes Copilot (Oct 28, 2026): no AI credits, usage billed to your budget

GitHub's pricing page now lists "GitHub Copilot access" in the Enterprise plan. There are no per-seat AI credits: Chat, code review and cloud agents draw on the company's AI budget.

Took effect Oct 282 days ago

What changed

GitHub redesigned its pricing page around Copilot. The page's banner changed from "Try GitHub, the complete developer platform" to "Try the Copilot-powered platform", and the Enterprise plan's tagline went from "Security, compliance, and flexible deployment" to "AI-powered development, governed at enterprise scale". The Enterprise box now opens with "GitHub Enterprise now includes access to GitHub Copilot." and its feature list starts with "GitHub Copilot access" and "Agent governance". Its comparison table lists Enterprise at $21 per user/month.

Change 1: Copilot comes with Enterprise, but with no AI credits. GitHub's changelog post from October 28, 2026 says enterprises "working with a GitHub or Microsoft account team can now get Copilot included with GitHub Enterprise for every licensed user." It has "the same features and models as Copilot Enterprise but does not include monthly AI credits per seat." Instead, "AI usage is metered from the first request against your enterprise budget" and "There is no included usage allowance to track or top up."

Change 2: what works when the budget runs out. Per the changelog, "Code completion and next edit suggestions keep working even with no budget available," while "Copilot Chat, Copilot code review, and Copilot in the cloud require available budget to use." It adds: "An exhausted budget never removes access."

Change 3: people without an Enterprise license. Users in an enterprise account who don't hold a GitHub Enterprise license "get the same Copilot access through Copilot Standalone, at $10 per user per month."

Who can get it now: only customers on GitHub Enterprise Cloud with an account team. For self-serve customers it is "Currently unavailable", and GitHub says it will open it "in stages and will share dates in the coming weeks." Copilot Business and Copilot Enterprise "remain available to purchase."

Other changes: the Team and Enterprise price boxes no longer carry the line "for the first 12 months". The Free and Team plans keep the same CI/CD minutes (2,000 and 3,000 a month) and Packages storage (500MB and 2GB).

Who it affects

Companies on GitHub Enterprise Cloud, and the developers and finance teams who manage their Copilot spend. Individuals and teams on Free or Team aren't affected, and self-serve Enterprise customers can't switch yet.

Quick answers

Does GitHub Enterprise include Copilot now?

Yes, for Enterprise Cloud customers working with a GitHub or Microsoft account team. GitHub's pricing page says "GitHub Enterprise now includes access to GitHub Copilot." Self-serve customers can't get it yet.

Does Copilot in GitHub Enterprise include AI credits?

No. GitHub's changelog says it "does not include monthly AI credits per seat" and that "AI usage is metered from the first request against your enterprise budget."

What happens when the AI budget runs out?

Code completion and next edit suggestions keep working. Copilot Chat, Copilot code review and Copilot in the cloud need available budget. GitHub says "An exhausted budget never removes access."
