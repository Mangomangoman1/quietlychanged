GitHub: AI secret detection now covers push protection, billed by usage

GitHub's AI password detection can now block pushes, but that feature is billed by usage instead of being included in Secret Protection.

The wording

struck removed underlined added

What changed

In the GitHub Secret Protection section of GitHub's pricing page, the "Copilot secret scanning" row is renamed "AI detection for alerts" ("Use AI to detect unstructured secrets, like passwords, in existing code"). A new row, "AI detection for push protection," uses AI to "detect unstructured secrets, like passwords, and block pushes that contain them," and is listed as "Usage-based" rather than included in the plan price.

Who it affects

Teams paying for GitHub Secret Protection, especially admins who want AI-based password detection to block pushes and need to budget for usage charges
