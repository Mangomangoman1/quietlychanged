Slack caps Slackbot at 15 messages a week on Business+

Three real changes today. Slack's Business+ plan now limits Slackbot to "15 messages per user each week," while unlimited Slackbot moves to Enterprise+, which now shows a $45 per user a month list price instead of "Contact sales." Microsoft 365 is running a 30%-off first term on Personal ($69.99 first year) and Premium ($139.99 first year), renewing at full price. Anthropic renamed Claude Dashboards to Claude Data and added Sheets and Whiteboards betas, with no price changes.

Noise skipped: Proton's pricing page switched to a Dutch-language plan comparison variant; Audible's plan cards rotated layout again; Reddit added a Gujarati language list; Venmo added a navigation menu; Delta fixed a typo; Cloudflare removed a stray space; Tubi's device ID and a Booking.com calendar value rotated. Fetch failures: PayPal terms and privacy (HTTP 403), Roblox (403), Shein (bot wall), Emotiv privacy (empty page).
