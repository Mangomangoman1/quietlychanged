Discoverable Server Web Presence. November 16, 2026 17:05 Updated
Web Presence is where you control what content from your Discoverable Server can appear publicly on its Server Web Page and in search engines like Google.
Note: Web Presence settings are available on desktop and browser only at this time. Only the server owner or members with the Administrator permission can change them, and bots can't change them.
How to Open Web Presence: 1. Open Server Settings. 2. Under Community, select Web Presence.
Server Web Presence manages two independent features. Each has its own toggle and its own list of eligible channels. Both toggles are under Discoverable Content on Web Pages and are on by default.
A server must be Discoverable to use Channel Summaries on the web or Channel Messages on the web. Private and role-restricted channels are not included.
Channels taking part in Channel Summaries or Channel Messages are labeled with the word "Discoverable" in the channel header.
Public channels in Discoverable Servers are included by default. You can change which ones are included at any time.
When you create a public text channel in a Discoverable Server, the channel creation window includes a Discoverable section where you can choose All Content, Summaries Only, Messages Only, or None.
Turn off the feature. Toggling off Channel Summaries or Channel Messages stops new content from being generated or shown going forward, but content already published may remain visible until individually removed.
Q: How do I know if my server is Discoverable? A: Open Server Settings > Access > Discoverable.
In some regions, members' Channel Messages setting is off by default, so their messages won't appear unless they turn it on.
Q: Can I stop my server from appearing on the web entirely? A: Turning off both Channel Summaries and Channel Messages stops new content from appearing, though content already published may remain visible (see the FAQ above). Your Server Web Page stays live while your server is Discoverable. To remove your Server Web Page, turn off Discoverability, which changes your server back to a Community Server.
Q: How are Channel Summaries created? A: Discord creates Channel Summaries using AI, based on recent discussions in your server's public channels. Summaries may not always be accurate.
