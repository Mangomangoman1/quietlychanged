PS Plus cloud storage
Automatically sync PS5 console data with cloud storage
You can automatically sync your saved data with cloud storage when you close a game or put your console in rest mode.
Cloud storage sync requires automatic updates to be enabled.
Go to Settings > System > Power Saving > Features Available in Rest Mode > Stay Connected to the Internet.
Go to Settings > Saved Data and Game/App Settings, then select Saved Data (PS5) or Saved Data (PS4).
For PS5 games, select Sync Saved Data > Auto-Sync Saved Data. 
For PS4 games, select Auto-Upload. 
For PS5 games, both your console and cloud storage will sync to the most recent data. For PS4™ games, data is automatically uploaded to your cloud storage, but will need to be manually downloaded to PS5 console storage.
 PS Plus cloud storage for PS5 consoles 
Automatically sync PS4 console data with cloud storage
Automatic uploads add saved data from your primary PS4 console to online storage:
Go to Settings > Power Saving Settings > Set Features Available in Rest Mode.
Select the check box next to Stay Connected to the Internet.
Go to Settings > Application Data Management > Auto-Upload.
Select the check box next to Enable Automatic Uploads.
 PS Plus cloud storage for PS4 consoles 
How to manage PlayStation Plus online storage on PS5 consoles
Highlight a game from your Games home, press the options button, and then select Upload/Download Saved Data. The game's most recent saved data is uploaded or downloaded.
 Learn more 
How to manage PlayStation Plus online storage on PS4 consoles
If automatic uploads aren't set up, or you want to upload a save from a friend's PS4 console, you will need to start uploads manually:
Select your local user and go to Settings > Application Data Management > Saved Data in System Storage > Upload to Online Storage.
Select the title and then the file you would like to upload and select Yes to overwriting the cloud file.

Cloud Streaming on PS Portal
Requirements for Cloud Game Streaming on PS Portal
A PlayStation Portal™ Remote Player. 
An account for PlayStation. Please note, Cloud Streaming is not available for child accounts.
An active PlayStation Plus Premium membership.
 To stream games, you need a subscription for PlayStation Plus Premium. Please check whether Cloud Streaming is supported in your country or region.
 PlayStation Plus membership plans 
Access to broadband internet
Minimum upload and download speeds for streaming: 
5 Mbps minimum to establish a cloud streaming session 
7 Mbps minimum to stream at 720p
13 Mbps minimum to stream at 1080p
 Learn more 
How to play a streaming game on PS Portal 
Select the Cloud Streaming tab from the options available in the top left of the device Home screen. 
Select the game you want to play from either Cloud Streaming with PlayStation Plus Premium, Streaming Games in PlayStation Plus, or an eligible game from Your Library. 
Select Stream. 
 The game starts when connected.

How to enable PS5 Console Sharing and Offline Play
PS5™ Console Sharing and Offline Play is automatically enabled on the PS5 console you use to sign in to PlayStation for the first time. To disable or enable Console Sharing on a new PS5 console, follow these steps:
Go to Settings > Users and Accounts > Other > Console Sharing and Offline Play.
Select Enable or Disable.
