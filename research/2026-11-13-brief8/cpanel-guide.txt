This licensing guide provides an overview of cPanel’s account-based pricing and licensing structure. Our pricing and
licensing is standardized for all of our customers, billed monthly, and includes multiple Tiers.




Who is this guide for?
This guide is for customers who purchased cPanel® products directly from the cPanel Store on our website, and want to
learn more about our licensing structure and pricing. We hope that this guide is a useful summary. Please refer to the
licensing information at https://www.cpanel.net/legal-notices/#end-user-license-agreement for specific terms.



Licensing explained
The price per license is based on the number of accounts hosted on the same server.

When purchasing a cPanel & WHM® license, the Tier, Type, and Packages will all need to be selected. The "Tier"
represents the number of accounts purchased. The "Type" is the server environment of choice, whether that is Cloud
(VPS) or Metal (Dedicated). "Package" represents the billing package, either Fixed or Auto-Scale (only available to
PartnerNOCs). When selecting a Fixed package, the Tier and Type will also need to be chosen. On an Auto-Scale package,
only the environment Type needs to be selected (because this package moves seamlessly through Tier based on usage).

A cPanel license includes both WHM® and cPanel interfaces. WHM, also known as Web Host Manager, is the root
administrator that manages cPanel account(s).



What is a cPanel account?
A cPanel account, sometimes called a cPanel user, is an account created by the root administrator or reseller, that logs into
the cPanel interface to manage their website.

Cloud environment are offered on all Account Tiers, while Metal environment are available on Premier. Below is an
overview of our pricing tiers and account limits for each Tier.

Packages Explained
A "Package" is a combination of account Tier (cPanel Solo®, Admin, Pro, or Premier) and License Type (Metal or Cloud)
that is generated according to what the license type a customer selects as their cPanel offering.
The cPanel Solo, Admin and Pro Tiers are fixed, meaning that an upgrade process is required through the Store or in-
product to move to a higher Account Tier. After upgrading to the Premier Tier, no further upgrades are needed to add
additional accounts because Tiers then auto-scale. Auto-scaling adjusts the number of licenses automatically based on
the number of accounts created on the server. Bulk accounts start when a server on a Premier Tier reaches 101 accounts.

Extended Lifecycle Support Program
CentOS 7 and CloudLinux 7 reached End of Life (EOL) support on June 30, 2024. This means that after that date,
these operating systems no longer receive security updates from upstream vendors. This makes them more
vulnerable to potential security issues.

We enrolled all servers running CentOS 7 or CloudLinux 7 on cPanel v110 in the Extended Lifecycle Support (ELS)
Program to provide critical security updates and technical support for qualifying servers.

ELS Program Fees
Servers running CentOS 7 or CloudLinux 7 on cPanel v110 that are enrolled in the ELS Program are charged an
additional monthly fee for the ELS Program’s additional security and support coverage. These fees are based on the
base cPanel license amount. The ELS Program started July 1, 2024.
