 What is a Server Web Page?
 A Server Web Page is a public page on the open web that helps people discover and learn about your Discoverable Server. Anyone can see it, including people without a Discord account, and search engines like Google can show it in their results. Beyond the content you add yourself, it may also show content from your server's public channels, such as Channel Summaries and Channel Messages. New members can join directly from this page.
 To manage which content appears on your page, see Server Web Presence .
 Which servers can create a Server Web Page?
 Server Web Pages are exclusive to Discoverable Servers.
 See Clarifying Server Types to learn how a Community Server can become Discoverable.
 How do I set up a Server Web Page?
 Automatic setup: If you don't set up your own Server Web Page for your Discoverable Server, Discord publishes a default one for you, built from your server's existing details from the Server Profile. You don't need to do anything for your Discoverable Server to have a page.
 To customize your Server Web Page:
 1. Open Server Settings on Discord desktop or browser.
 2. Under Community , select Web Presence .
 Web Presence is under Community in Server Settings. 
 3. Edit your server’s Landing Page .
 Complete each requirement in the Landing Page panel, then select Publish Landing Page . 
 4. Once your page is live, select View Page to see it. You can update your page content at any time after publishing.
 What content should I add to my Server Web Page?
 All web page content needs to abide by Discord’s Discovery Guidelines . Discord’s Trust and Safety team may remove web pages that violate these guidelines, and consider whether further action is necessary.
 Describe your server in ways that help people find it. When adding content to your web page, use words that describe your community accurately and specifically. This will help new community members easily find your server when they’re searching the web for relevant terms. If your server is for underwater basket weaving enthusiasts, use these words rather than more generic ones. Your next basket weaver may be just one search term away!
 What content can appear on my Server’s Web Page?
 Channel Summaries. A small slice of what's being talked about in your server, directly on your Server Web Page. These automated summaries only cover conversations from November 16, 2026, onwards. Admins can change which channels they draw from, curate the summaries that are shown, or turn them off entirely. Usernames will not be shown in summaries.
 Channel Messages. From mid-December 2026, answers to questions your members sent in public channels can be found in a web search, in their own words. Server admins decide which channels take part, and server members can opt out of having their own messages appear. Usernames will not be shown alongside these messages.
 Summaries on the web and Messages on the web are controlled independently; each has its own settings for which channels are included. See Server Web Presence to manage them.
 Can I turn off my Server Web Page?
 A Server Web Page is a required part of being a Discoverable Server. If you don't want a public page, you can turn off Discoverability, which reverts your server to a Community Server. See Clarifying Server Types for how to turn off Discoverability and what changes when you do.
 To turn off Discoverability, go to Access and select Invite Only or Apply to Join . 
 You can still control what appears on your page. Server Settings > Web Presence lets you edit your server’s landing page, and separate controls let you turn off Channel Summaries or Channel Messages for specific channels without leaving Discoverable status.
 Turn Channel Summaries and Channel Messages on or off separately in Web Presence . 
 See Server Web Presence for those settings.
 Does my server need a specific Boost Level?
 No. Server Web Pages are available to all Discoverable Servers, regardless of Boost Level.
